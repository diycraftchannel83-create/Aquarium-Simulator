# Aquarium Fish GLB Assets

Procedurally generated glTF 2.0 binary starter meshes for Aquarium Simulator.

Included models:
- `clownfish.glb` — orange fish with pale body bands.
- `blue_tang.glb` — blue body with yellow fins.
- `angelfish.glb` — tall body with elongated dorsal and anal fins.
- `neon_tetra.glb` — compact schooling fish.

Each model contains a tapered body, fins, paired eyes, vertex colors and a metallic-roughness PBR material. The models use `KHR_mesh_quantization` for compact normal attributes. Coordinate convention: forward +X, up +Y, depth +Z.

These are compact static starter meshes without embedded skeletal animation clips. Runtime swimming/fin animation, richer anatomical detail and artist review remain necessary before claiming photorealistic premium quality.
